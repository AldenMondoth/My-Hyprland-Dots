# My Dotfiles for Ubuntu Hyprland 0.56+

A lot of the dotfiles were originally in hyprlang, which I lua-fied after updating to 0.56

### three types of changes from JaKooLit:

+ -> No change whatsoever, keeping a lot of the bash scripts and making minor changes :)
+ -> directly converting from hyprlang to the Hyprland Lua API - all the UserConfig files are a direct port to lua, with a few modifications in code logic
+ -> Complete change in code and logic - the animations and system settings were designed and tuned by me
    

This is not a finished project. For instance, I eventually would want the scripts to be rewritten in lua if possible, and also move from WayBar to a custom QuickShell implementation.


Make sure to double check if your stuff is compatible, and also double check the [**hyprland wiki**](https://wiki.hypr.land/).
